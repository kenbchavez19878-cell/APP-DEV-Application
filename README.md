This system is designed to streamline the management of social welfare programs, specifically focusing on tracking beneficiaries and managing OFW/OWWA-related assistance. It provides a digital "source of truth" to replace manual paper-based tracking.

### 🛠 Tech Stack
* **Frontend:** React.js (Vite)
* **Styling:** Tailwind CSS
* **Backend Environment:** Node.js
* **Package Manager:** npm
* **Version Control:** Git & GitHub
